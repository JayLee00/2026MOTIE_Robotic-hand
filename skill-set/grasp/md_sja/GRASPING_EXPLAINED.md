# Top-down Grasping 동작 설명 (팀 공유용)

> KISTAR FR3 팔 + KISTAR Dexterous Hand 기반 top-down 파지 파이프라인이 **어떻게 물체를 잡는지** 전체 과정과 설정을 정리한 문서.

---

## 1. 한 줄 요약

**카메라로 물체를 보고 → "어디를·어떤 각도로 잡을지" 계산 → 로봇 팔이 그 위치로 가서 → 손을 오므려 집는다.**

- 팔(EE) 자세는 **물체마다 비전으로 계산** (SAM3 + PCA)
- 손(손가락 16개) 자세는 **고정 프리셋** (configs/hand.yaml)

---

## 2. 전체 파이프라인 (흐름)

```
① 카메라 촬영         RealSense D435i → RGB + Depth
② 물체 검출           SAM3: 텍스트("orange") → 2D 마스크
③ 3D 점구름 생성       마스크 + Depth → back-project → 포인트클라우드
④ 팔 파지 자세 계산     PCA로 물체 방향 분석 → 6D pose (위치+방향)
⑤ 손 파지 자세 결정     hand.yaml 고정 프리셋 (오므리기)
⑥ IK & 경로 계획       trac_ik(역기구학) + OMPL(경로)
⑦ 로봇 실행           접근 → 하강 → 쥐기 → 들기 (4단계)
```

---

## 3. 단계별 상세

### ③-1. 카메라 캡처 (RGB-D)
- Intel RealSense D435i로 **컬러(RGB) + 깊이(Depth)** 동시 촬영
- Depth는 각 픽셀까지의 거리(m)를 담음

### ③-2. 물체 검출 — SAM3 (2D 마스크)
- **SAM3** = 텍스트로 물체를 찾는 분할(segmentation) AI 모델
- 입력: RGB 이미지 + 텍스트(예: `"orange"`)
- 출력: **2D 마스크** (어느 픽셀이 그 물체인지) + 신뢰도(score)
- ⚠️ SAM3는 **2D까지만** — 3D는 다음 단계에서 Depth로 만듦

### ③-3. 포인트클라우드 생성 (back-project, 핀홀 카메라 모델)
- 마스크 안 각 픽셀에 **Depth**를 입혀 3D 점으로 변환:
  ```
  X = (u - cx)·Z / fx
  Y = (v - cy)·Z / fy      (핀홀 카메라 표준 공식)
  Z = Depth
  ```
- 결과 = 물체 표면의 **3D 점구름**(포인트클라우드)
- 노이즈 제거(SOR) 후 카메라 좌표 → 로봇(world) 좌표로 변환 (캘리브레이션)

### ③-4. 팔(EE) 파지 자세 계산 — PCA 기반 ⭐
물체 점구름을 **위에서 내려다본(top-down)** 자세를 계산:

1. **높이(z_top)**: 점들 중 물체 윗면 (95퍼센타일)
2. **위치(중심)**: 윗부분 점들의 XY 평균
3. **방향(yaw)**: **PCA(주성분분석)** 로 물체가 가장 길쭉한 방향(장축)을 찾음
   - 손가락은 그 장축에 **수직(+90°)** 으로 닫아야 안정적 (폭을 가로질러 잡기)
   - 손이 팔에 비스듬히 장착된 각도(**-45°**)도 더함
   - `최종 손목각 = -45°(장착) + PCA보정`
4. **자세**: 위에서 아래로 수직(top-down) + 손목을 물체 방향에 맞춰 회전
5. 결과 = **6D 파지 pose** (위치 xyz + 방향)

> **PCA는 표준 통계기법**(SVD)을 그대로 쓰고, "장축에 수직으로 잡는다"는 **파지 전략은 자체 설계**.

### ③-5. 손(Hand) 파지 자세 — 고정 프리셋 (§4에서 상세)
- 팔은 물체마다 계산하지만, **손가락은 정해진 자세로 오므림**
- 3가지 프리셋(대기/파지/릴리즈)을 configs/hand.yaml에서 정의

### ③-6. IK & 로봇 실행
- 6D pose를 **trac_ik(역기구학)** 로 풀어 → 팔 관절 7개 값 산출
- **OMPL** 로 충돌 없는 경로 계획
- 실행 4단계 (각 단계 사용자 y/n 확인 + 도달 피드백):
  ```
  ① 접근(approach) : 물체 위 10cm로 이동
  ② 하강(descend)  : 물체까지 수직 하강
  ③ 쥐기(grasp)    : 손 오므리기 (hand_grasp)
  ④ 들기(lift)     : 다시 위로
  ```

## 4. 손(Hand) 설정 상세 — `configs/hand.yaml`

> **이 파일 하나만 수정하면 run_topdown_grasp.py와 robot_executor.py 모두 반영됨.** (각도 단위: degrees)

### 4-1. 전체 설정

```yaml
abduction_deg: 15.0           # 손가락 외전각 (index: -15°, ring: +15°)

motion:
  steps: 30                   # 손가락 이동 보간 스텝 수
  period_sec: 0.02            # 스텝 간격 → 총 0.6초에 걸쳐 부드럽게

hand_init:                    # 대기 / 접근 자세 (충돌 회피)
  thumb_j1_deg:   90.0
  thumb_j2_deg:  -90.0
  finger_j3_deg:  67.5        # 세 손가락 살짝 굽힘

hand_release:                 # 릴리즈 (완전 펴기)
  thumb_j1_deg:   90.0
  thumb_j2_deg:  -90.0
  finger_j3_deg:   0.0        # 완전 펴짐

hand_grasp:                   # 파지 (완전히 쥐기, FIXED)
  thumb_j1_deg:   90.0
  thumb_j2_deg:  -90.0
  finger_bend_deg: 90.0       # 세 손가락 j1~j3 완전 구부림
```

### 4-2. 3가지 손 자세의 역할

| 자세 | 언제 | 손가락 상태 |
|---|---|---|
| **hand_init** | 접근·하강 중 (충돌 회피) | 세 손가락 **살짝 굽힘**(67.5°) |
| **hand_grasp** | 물체 쥘 때 | 세 손가락 **완전 구부림**(90°) + 엄지 마주보기 |
| **hand_release** | 물체 놓을 때 | **완전 펴기**(0°) |

### 4-3. 파라미터 의미

- **abduction_deg (15°)**: 손가락 좌우 벌림. index는 −15°, ring은 +15°로 벌려서 물체를 감싸는 폭 확보
- **thumb_j1 / thumb_j2 (90° / −90°)**: 엄지를 세워 세 손가락과 **마주보게**(opposition) — 물체를 양쪽에서 집는 형태
- **finger_bend_deg (90°)**: index·middle·ring 손가락의 j1~j3 관절을 90°까지 구부림 = 완전히 쥠
- **finger_j3_deg**: init(67.5°, 살짝) / release(0°, 폄) 시 손가락 굽힘 정도
- **motion (30스텝 × 0.02초)**: 손을 **한 번에 확 안 움직이고 0.6초에 걸쳐 부드럽게** 보간

### 4-4. 16-DOF 구조 (참고)

손가락 4개 × 관절 4개 = 16 자유도. 파지 시:
```
index  : [-15°(벌림), 90°, 90°, 90°]   ← 완전히 구부림
middle : [  0°,       90°, 90°, 90°]
ring   : [+15°(벌림), 90°, 90°, 90°]
thumb  : [ 90°, -90°,     90°, 90°]     ← 마주 세우기
```
- 각도는 엔코더 값으로 변환되어 로봇에 전송 (90° → 엔코더 4096)

### 4-5. ⚠️ 현재 방식의 특성 (중요)

- **손 자세는 물체와 무관하게 고정** — 크기·모양 상관없이 항상 "90° 풀 그립"
- 장점: 단순·안정적
- 한계: 작은 물체는 헐겁고, 큰 물체는 과하게 쥘 수 있음. **접촉 피드백 없이 열린 루프(open-loop)** 로 쥠 (실제로 잡혔는지 모름)
- → **개선 방향**: 촉각 센서(PaXini)로 "닿을 때까지만 쥐기"(적응형) 및 파지 성공/실패 감지 (§7)

## 5. 설정 파일 요약 (어디를 바꾸나)

| 파일 | 설정 내용 |
|---|---|
| **configs/hand.yaml** | 손가락 자세 (쥐는 각도, 벌림, init/release) |
| **configs/arm.yaml** | 파지 높이(z_offset), 접근 거리, EE 위치보정, PCA 파라미터 |
| **configs/fruits.yaml** | **물체별** 미세보정 (예: orange의 x/z offset) |
| scripts/run_topdown_grasp.py | 파지 자세 **계산 로직**(PCA 등) — 코드 |

---

## 6. 물체별 특성 / 알려진 한계

- **길쭉한 물체(바나나·배)**: PCA로 장축이 명확 → 방향 계산 정확 ✅
- **둥근 물체(오렌지·사과·공)**: 장축이 없어 PCA 각도가 **노이즈로 불안정** ⚠️
  - 둥근 물체는 어느 각도로 잡아도 되므로, PCA를 끄고 **고정 각도**로 잡는 것이 안정적 (개선 예정)
- **물체별 위치/높이 미세오차**: configs/fruits.yaml에 물체별 x/y/z offset으로 보정

---

## 7. 현재 한계 & 개선 방향

| 현재 | 개선 |
|---|---|
| 손을 **고정 90°로 무조건** 오므림 | **촉각(PaXini)으로 닿을 때까지만** 쥐기 (적응형) |
| 잡았는지 **모름** (open-loop) | 촉각으로 **파지 성공/실패 감지** |
| 미끄러짐 대응 없음 | 촉각 slip 감지 → 재파지/힘조절 |
| 둥근 물체 PCA 불안정 | 둥근 물체 자동 감지 → 고정 각도 |

> KISTAR 핸드에 **PaXini 촉각 센서**(손가락당 15지점 × 4손가락 = 60점) 장착돼 있고, 데이터 수신 확인됨. 향후 파지 로직에 통합 예정.

---

## 8. 핵심 정리 (팀 공유용 3줄)

1. **팔 자세** = 카메라로 물체를 보고 SAM3+PCA로 "어디를·어떤 각도로 잡을지" **물체마다 계산**
2. **손 자세** = configs/hand.yaml의 **고정 프리셋**으로 오므림 (물체 무관, 90° 풀 그립)
3. **실행** = trac_ik로 관절 풀고 → 접근·하강·쥐기·들기 4단계로 파지
